# Background scene photos (optional)

The background picker works fully out of the box with **CSS-generated gradient
scenes** — no images required. This folder lets you optionally layer a real
CC0 ("no rights reserved") photo on top of each gradient for extra realism.

If a file below is missing, that scene simply falls back to its gradient —
nothing breaks, nothing errors. Add files here with these **exact filenames**
to activate photo backgrounds:

| Filename          | Scene              |
| ------------------ | ------------------- |
| `rain.jpg`          | Rainy Window        |
| `forest.jpg`        | Forest               |
| `ocean.jpg`         | Ocean                |
| `night.jpg`         | Night Sky            |
| `mountains.jpg`     | Mountains at Dusk    |
| `fireplace.jpg`     | Cozy Fireplace       |

## Where to find CC0 photos

- [Pixabay Images](https://pixabay.com/images/) — filter by "All images",
  free to use without attribution.
- [Unsplash](https://unsplash.com/) — free license, attribution appreciated
  but not required.
- [Pexels](https://www.pexels.com/) — free license, no attribution required.

Pick wide, landscape-orientation photos (1920x1080 or larger) with a fairly
dark or low-contrast composition — the app renders a dark gradient overlay on
top for text readability, so busy or very bright photos can end up looking
washed out. Keep file sizes reasonable (a few hundred KB, compressed JPEG) —
this is a client-side app with no server-side image optimization.
